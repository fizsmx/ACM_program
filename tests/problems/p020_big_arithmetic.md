# Huge Numbers

Your calculator broke and you must add and multiply very large non-negative integers by hand. Write a program that does it for you.

Input
The first line contains T (1 ≤ T ≤ 50). Each of the next T lines contains two non-negative integers A and B, each with at most 1000 decimal digits and without leading zeros (the number 0 is written as a single digit).

Output
For each pair print A + B and A × B separated by one space.

Sample Input
3
123456789012345678901234567890 987654321098765432109876543210
0 99999999999999999999
1 1

Sample Output
1111111110111111111011111111100 121932631137021795226185032733622923332237463801111263526900
99999999999999999999 0
2 1
