# Divisor Statistics

For a positive integer n let d(n) be the number of positive divisors of n and s(n) the sum of those divisors. You must answer several queries of the form "what are d(n) and s(n)?".

## Input
The first line contains an integer q (1 ≤ q ≤ 10^5), the number of queries. Each of the following q lines contains one integer n (1 ≤ n ≤ 10^6).

## Output
For every query print d(n) and s(n) separated by one space, in the order the queries were given.

## Sample Input 1
3
1
6
12

## Sample Output 1
1 1
4 12
6 28

## Sample Input 2
2
7
100

## Sample Output 2
2 8
9 217
