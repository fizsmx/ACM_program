# Trailing Zeros and Digit Sum

For each query n, print two numbers: the number of trailing zeros of n! (n factorial) and the sum of the decimal digits of 2^n.

## Input
The first line contains q (1 ≤ q ≤ 100). Each of the next q lines contains an integer n (0 ≤ n ≤ 1000).

## Output
For each query print the two numbers separated by a space.

## Example
Input
3
5
10
0
Output
1 5
2 7
0 1
