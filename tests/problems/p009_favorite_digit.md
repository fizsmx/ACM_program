# Favorite Digit

You are given a string s consisting only of decimal digits. Find the digit that appears most often in s. If several digits share the maximum frequency, choose the largest of them. Print that digit followed by its number of occurrences.

## Input
A single line with the string s.

## Output
Print the chosen digit and its frequency separated by a space.

Example 1:
Input: 1122233
Output: 2 3
Explanation: The digit 2 appears three times, more than any other digit.

Example 2:
Input: 9090
Output: 9 2
Explanation: Digits 9 and 0 both appear twice; the larger digit wins.

Example 3:
Input: 7
Output: 7 1

Constraints:
1 <= |s| <= 10^5
s contains only the characters 0-9.
