# Count Pairs With Given Sum

You are given an array of n integers and an integer k. Count the number of pairs (i, j) with i < j such that a_i + a_j = k.

## Input
The first line contains two integers n and k (1 ≤ n ≤ 2·10^5, -10^9 ≤ k ≤ 10^9).
The second line contains n integers a_1, ..., a_n (-10^9 ≤ a_i ≤ 10^9).

## Output
Print a single integer: the number of such pairs.

## Examples
Input
5 6
1 5 3 3 2
Output
2

Input
4 10
5 5 5 5
Output
6
