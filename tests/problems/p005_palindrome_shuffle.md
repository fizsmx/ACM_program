# Palindrome Shuffle

A word is called shuffle-palindromic if its letters can be rearranged so that the result reads the same forwards and backwards. For every word given, decide whether it is shuffle-palindromic.

Input
The first line contains an integer T (1 ≤ T ≤ 100), the number of words. Each of the next T lines contains one word made of lowercase English letters. The length of every word is between 1 and 10^5.

Output
For each word print YES if it is shuffle-palindromic and NO otherwise, one answer per line.

Sample Input
4
level
abc
aabbcc
xyzzyx

Sample Output
YES
NO
YES
YES
