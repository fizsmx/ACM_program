# Next Prime

For each of T integers n, print the smallest prime number that is greater than or equal to n.

## Input
The first line contains T (1 ≤ T ≤ 10^5). Each of the next T lines contains one integer n (1 ≤ n ≤ 10^6).

## Output
For every n print the answer on its own line.

## Examples

**Input**
```
4
1
10
13
100
```

**Output**
```
2
11
13
101
```

**Input**
```
1
1000000
```

**Output**
```
1000003
```
