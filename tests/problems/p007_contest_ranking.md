# Contest Ranking

After a programming contest you are given the final score of every contestant. Produce the ranking: contestants with a higher score come first, and contestants with the same score are ordered alphabetically by name.

### Input
The first line contains an integer n (1 ≤ n ≤ 10^5).
Each of the next n lines contains a name (1 to 20 lowercase letters, all names distinct) and an integer score (0 ≤ score ≤ 10^9).

### Output
Print the n names, one per line, in ranking order.

### Example 1
Input:
```
5
alice 90
bob 95
carol 90
dave 80
erin 95
```
Output:
```
bob
erin
alice
carol
dave
```
